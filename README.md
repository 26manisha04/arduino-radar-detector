#Arduino-radar-detector

This project demonstrates a basic radar detection system using an Arduino Uno, Ultrasonic Sensor (HC-SR04), and a Servo Motor. The system scans the environment by rotating the ultrasonic sensor and detects objects within a specified range. The distance and angle of detected objects are displayed on the serial monitor.

Key Features:
1. Object detection using ultrasonic sensor
2. Servo motor to rotate and scan the environment
3. Real-time data visualization for distance and angle
4. Simple Arduino-based setup for radar-like functionality

Components Used:
1. Arduino Uno
2. HC-SR04 Ultrasonic Sensor
3. Servo Motor (e.g., SG90)
4. Jumper Wires
5. Breadboard

Instructions:
1. Connect the components as per the circuit diagram.
2. Upload the provided Arduino code to the board.
3. Open the serial monitor to view the object detection data (distance and angle).
4. The sensor will rotate and detect objects within range.

Installation:
1. Download the project files.
2. Open the Arduino IDE and load the Radar_Detector.ino file.
3. Upload the code to your Arduino board.
4. Check the serial monitor for distance and angle outputs.
